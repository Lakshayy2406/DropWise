# 💧 DropWise

A responsive informational website focused on **water conservation, rainwater harvesting, sustainability, and community awareness**.

## 🌱 Overview

DropWise presents educational content and resources around responsible water usage and sustainable environmental practices through informational pages, visual content, and interactive front-end elements.

## ✨ Features
- 🏠 Responsive home page
- 💧 Water conservation awareness
- 🌧️ Rainwater harvesting information
- 🌿 Sustainability and environmental content
- 🖼️ Image gallery
- 📖 About and informational sections
- 📩 Contact section
- 📚 Tips and educational content

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript

## 🚀 Run Locally

```bash
git clone https://github.com/Lakshayy2406/DropWise.git
cd DropWise
```

Open `index.html` in a browser, or use VS Code Live Server.
